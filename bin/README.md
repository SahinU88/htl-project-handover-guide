# Executable

This folder contains a ready-to-run build of your application (for example the `.exe`).

Please describe here how to start the application and what is needed to run it:

- **How to start:** which file to run (for example `MyApp.exe`)
- **Requirements:** anything that must be installed (for example .NET Runtime version,
  a specific operating system)
- **Data files:** if the app needs a data file to run (for example a `customers.csv`),
  say where it has to be placed

> Tip: test the executable on a different computer or a fresh folder to make sure nothing
> is missing.

# Project Learnings

This document has **two parts** in one file:

1. **What you learned** during the project (~1 page A4)
2. **Feedback on our course & material** (~0.5 page A4)

Be honest. This is not graded on "everything was perfect". Reflecting on what was hard and
what was missing is exactly the point.

---

## 1. What we learned (~1 page)

Describe the topics where you had the feeling you **learned something new** or **applied**
something in a new way. This can be technical or non-technical. A few prompts to help you:

- Which **technical topics** did you learn or deepen? (e.g. WPF data binding, working with
  CSV files, error handling, Git, ...)
- Which **non-technical things** did you learn? (e.g. teamwork, planning, splitting tasks,
  meeting deadlines, asking for help, ...)
- What was the **biggest challenge** and how did you solve it?
- What would you **do differently** next time?

> **Example (replace with your own):**
>
> - **WPF data binding:** At first we updated the UI manually in code. We learned how to use
>   `INotifyPropertyChanged` so the UI updates automatically when the data changes. This made
>   our code much shorter and easier to understand.
> - **Working with CSV:** We learned that real data is messy. Empty lines, wrong separators
>   and missing values made our app crash, so we learned to validate input before using it.
> - **Teamwork & planning:** Splitting the work into small tasks helped us, but we
>   underestimated how long testing would take. Next time we would plan more time for it.

---

## 2. Feedback on the course & material (~0.5 page)

Help us improve the course. Please answer honestly:

- Was the **course content and material enough** to work on your project?
- Did you **miss any topics** that would have helped you? (which ones?)
- Were any topics **too shallow** and should have been taught in more detail?
- Were any topics covered **well** / just right?

> **Example (replace with your own):**
>
> - The material on **C# basics and WPF** was enough to get started and build the UI.
> - We **missed a deeper introduction to file handling** (reading/writing CSV). We had to
>   learn most of it ourselves and from AI tools.
> - **Git** was only covered briefly; a bit more on branches and merge conflicts would have
>   helped us when working as a team.
> - Overall the course gave us a good foundation to work independently on the project.
